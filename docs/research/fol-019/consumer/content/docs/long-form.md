这一页是 FOL-019 为长文阅读单独加入的内容样张。它不属于 FOL-014 的历史 fixture，
只用于观察默认样式在长正文、密集代码、宽表格与多层引用下的表现；正文里的所有结构
都由 `@uichat-mira/folio` 的默认 Markdown 渲染与默认样式表提供，消费者没有写任何
额外 CSS。

## 长正文的阅读节奏

长文阅读最先暴露的是节奏问题：段落间距是否一致、标题前后的留白是否成比例、行高在
连续多段中文里是否仍然稳定。默认样式用 `--folio-space-*` 与固定行高控制这些间距，
本节用连续段落验证它们在长页面里不会逐段漂移。

默认正文使用 16px 字号与 1.78 的行高比例，段间距来自排版变量而不是每个段落的
内联样式。把这段文字重复成多段后，页面的纵向节奏应当保持一致：标题前留白更大，
段落之间留白较小，列表项之间的间距又小于段落间距。

第二段继续检查同样的性质。若段落间距不一致，通常意味着某一段被额外的 `margin`
或 `<br>` 撑开；这类问题在长文里会累积成明显的节奏断裂，而在短页面里几乎看不出来。

第三段用于观察连续段落的行宽。桌面端正文列宽由 `.folio-doc-main` 控制，手机端
列宽跟随视口减去左右内边距；两种宽度下都不应出现文字被静默裁切或页面横向滚动。

### 三级标题与层级

三级标题比二级标题更轻，通常用于把一节拆成几个可跳转的小节。页内目录会同时收录
二级与三级标题，并用不同的缩进区分深度。

#### 四级标题的边界

四级标题在页内目录里仍然可见，但默认样式只保留较小的字号差异。这一层通常只用于
非常长的文档；如果一节里出现过多四级标题，说明这一节可能需要拆成独立文档。

## 代码块与长行

代码块使用默认的等宽字体与深色背景，行内代码则使用浅色背景。长代码行不应该把
整个页面撑宽，而应该由代码块自己横向滚动。

```ts
import { FolioApp, type FolioDoc } from "@uichat-mira/folio";
import "@uichat-mira/folio/styles.css";
import docs, { roots } from "virtual:folio/content";

const content: FolioDoc[] = docs;
const veryLongLine = "这一行故意写得很长，用来确认代码块在窄视口下由 pre 自己横向滚动，而不是把整页撑出水平滚动条。";

export function App() {
  return <FolioApp config={{ title: "Long form", description: "Long form sample" }} docs={content} basePath={import.meta.env.BASE_URL} />;
}
```

```css
.folio-doc-main .folio-markdown pre {
  overflow-x: auto;
  padding: var(--folio-space-md);
  border-radius: var(--folio-radius-md);
}
```

行内代码示例：`staticRoutes: false` 与 `staticRoutes: {}` 是两条不同的输出路径，
前者只产出 SPA 壳，后者由包内的静态生成器写出预渲染 HTML。

## 表格与窄视口

表格在桌面端按内容自然分配列宽，在手机端应保持可读并允许容器内滚动或换行，不能
把正文列撑出视口。

| 观察项 | 桌面 1440×900 | 手机 375×812 | 判定方式 |
| --- | --- | --- | --- |
| 正文列宽 | 约 820px | 视口宽减 32px | `getBoundingClientRect` |
| 行高 | 28.48px | 28.48px | computed style |
| 代码块 | 容器内横向滚动 | 容器内横向滚动 | `scrollWidth` / `clientWidth` |
| 分页 | 双向可见 | 双向可见 | 链接数量与 href |
| 页内目录 | 右侧常驻 | 折叠为面板 | 可见性与矩形 |

### 表格里的长文本

| 场景 | 说明 |
| --- | --- |
| 连续中文 | 不应出现单词级别的异常断行，标点应遵循默认换行规则 |
| 英文标识符 | `virtual:folio/content` 这类长标识符在窄列里允许自然换行 |
| 数字与单位 | `1440×900`、`375×812` 保持同一行，不应被拆成两行 |

## 引用与嵌套列表

> 一级引用用于强调一段结论。默认样式给引用块左侧的强调线，并降低文字对比度。
>
> > 二级引用很少出现，但 Markdown 允许嵌套。这里用它确认嵌套引用不会累积出
> > 过大的左内边距，也不会把正文挤到不可读的宽度。
