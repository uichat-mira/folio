这一页是 FOL-014 浏览器验收的主场景。页面里的所有结构都来自
`@uichat-mira/folio` 的默认实现，消费者只写了入口文件与三篇 Markdown。

## 页面结构

默认界面把一次文档阅读拆成固定的几块：

- 顶部是品牌、主导航、主题切换与搜索入口；
- 左侧是当前文档集合的目录，按 `section` 分组；
- 中间是标题、正文与上一篇/下一篇分页；
- 右侧是当前页的标题大纲，随滚动高亮当前位置。

### 侧栏与目录的分工

侧栏回答“我在文档集合的哪里”，页内目录回答“我在这一页的哪里”。两者都来自同一份
内容清单：侧栏用 `collection` 与 `section` 分组，页内目录来自正文里的二到四级标题。

窄屏下这两个导航都会被折叠：侧栏变成抽屉，页内目录变成可展开面板，入口固定在正文
上方的移动工具条上。

### 正文排版

默认样式对正文提供标题层级、段落间距、列表、引用、表格与代码块的基线排版。下面这些
块用来观察这些基线在桌面与手机两档视口下的实际表现。

> 引用块用于验证默认排版的强调样式，同时确认长段中文在窄视口下不会顶破容器。

代码块：

```ts
import { FolioApp } from "@uichat-mira/folio";
import docs from "virtual:folio/content";

export const app = <FolioApp config={{ title: "Docs", description: "Docs" }} docs={docs} />;
```

表格：

| 视口 | 宽度 | 期望 |
| --- | --- | --- |
| 桌面 | 1440 px | 侧栏、正文、页内目录三栏同时可见 |
| 手机 | 375 px | 侧栏折叠为抽屉，页内目录折叠为面板 |

## 明暗两种主题

主题切换写在 `<html>` 的 `data-folio-theme` 上，并同步写入 `localStorage`。默认跟随
系统偏好，用户手动切换后以用户选择为准。本页会在亮色与暗色下各被测量一次。

## 分页与相邻文档

正文末尾的分页来自同一集合内的排序结果。点“下一篇”或“上一篇”会做客户端路由跳转，
不会整页刷新，这一点在验收里通过 URL 与标题的联动变化确认。

## 可读性观察点

判断默认 UI 是否“清晰可读”时，本页记录的是可复核的数值：正文字号、行高比、文字与
背景的对比度、标题与正文的间距，以及页面是否出现异常水平溢出。最终的视觉判断仍然交给
维护者。
